Freight Rate & ETA API

A small REST API that estimates freight cost and delivery time between US cities.

GET /health — liveness check
GET /api/meta — list of supported cities & modes
POST /api/quote — get a rate + ETA estimate 
curl -X POST /api/quote -H "Content-Type: application/json" -d '{
  "origin": "Orlando, FL",
  "destination": "Atlanta, GA",
  "mode": "Truck",
  "weight_lbs": 1200
}'
